# Bakerization NEWS の初回設定

## 1. 接続を確認する

1. `news_list_posts`（`limit: 3`）を呼ぶ。**読み取りだけ**で確認し、記事の作成や更新はしません。
2. 成功したら、最新の記事タイトルを見せて「接続できました」と伝える。
3. ツールが見つからない・エラーになる場合:
   - 未接続なら、ホストの接続フローで Bakerization にログインして同意するよう案内する（ログイン・同意はユーザー本人が行う）。
   - ログインできているのに `news_*` ツールがない場合は、管理者ではないアカウントで接続しています。管理者アカウントで接続し直すよう伝える。
   - パスワード・トークン・Cookie を聞いたり保存したりしない。

## 2. 毎週の定期タスクを作る

ユーザーに次の内容でよいか確認してから、ホストの定期タスク（スケジュール）機能で作成します。

- 名前: `パン業界ウィークリーを公開`
- 頻度: 毎週月曜 7:00（Asia/Tokyo）— RRULE `FREQ=WEEKLY;BYDAY=MO;BYHOUR=7;BYMINUTE=0`
- プロンプト:

  > Bakerization NEWS プラグインの weekly-news スキルに従って、先週（月曜〜日曜、日本時間）のパン業界ウィークリーを日本語と英語で作成し、bakerization.com/news に公開してください。今週号が既にあれば何もせず終了してください。終わったら公開URLと載せたニュースの見出しを報告してください。

曜日・時刻はユーザーの希望があれば変更します。定期タスクを作る機能がこの画面にない場合は、上の内容をそのまま見せて、
ChatGPT の「スケジュール」から手動で作るよう案内します（パソコンを閉じていても動くよう、Web 版で作るのがおすすめ）。

## 3. 書き込みの承認について伝える

定期タスクは無人で動くため、記事の公開（`news_create_post`）で毎回承認を求められると止まってしまいます。
プラグインの設定で Bakerization NEWS の書き込み操作を「常に許可」にしてもらうよう案内します。

## 4. まとめて伝える

- 次回の実行日時
- 止め方（ChatGPT のスケジュール一覧から一時停止・削除）
- 公開された記事の修正・非公開・削除は https://www.bakerization.com/admen/news からできること
- 試しに今すぐ1本作る場合は「先週のパン業界ウィークリーを作って公開して」と頼めばよいこと
